# Manuscript revision checklist

1. Update Abstract with NCA/LMNN comparison results only after experiments are run.
2. Update Introduction contributions to mention direct established metric-learning comparisons.
3. Extend Related Work to distinguish supervised metric learning from screening.
4. Extend Methodology with NCA/LMNN protocol and hyperparameters.
5. Add a Results subsection: `Comparison with established metric-learning methods`.
6. Add a table with accuracy, weighted F1, runtime, and APG search reduction.
7. Update statistical tests to include new baselines where scientifically meaningful.
8. Remove the old limitation stating that no NCA/LMNN experiments were performed.
9. Keep the local-theorem scope clarification unchanged.
10. Add the repository URL and commit/tag in the Data and Reproducibility Statement.
11. Do not claim APG-AMS replaces NCA/LMNN.
12. Do not claim significance or superiority unless supported by generated results.
