# APG-AMS

Reproducibility artifact for **APG-AMS: Entropy-Guided Screening for Adaptive Metric Search in Distance-Based Learning** (Array manuscript `ARRAY-D-26-04165`).

This revision artifact directly addresses the reviewers' requests for deeper comparisons across datasets and algorithms.

## Comparison suite

Five methods are evaluated on common outer 10-fold stratified folds:

- Euclidean k-NN (`L2`)
- full local Minkowski p-search over `{1, 1.5, 2, 3, 4}`
- APG-AMS
- Neighborhood Components Analysis (NCA) + k-NN
- Large Margin Nearest Neighbor (LMNN) + k-NN

The original eight datasets are retained. Four additional real-world UCI datasets are added: Ionosphere (ID 52), Sonar (ID 151), Banknote Authentication (ID 267), and Mice Protein Expression (ID 342). This yields 12 datasets in the revised experiment suite.

## Evaluation safeguards

- All methods use the same outer stratified folds.
- Missing-value imputation is fit on the training fold only.
- Standardization is fit on the training fold only.
- NCA and LMNN are trained on the training fold only.
- No test labels are used for preprocessing or model fitting.
- Accuracy and weighted F1 are reported for all methods.
- End-to-end fold runtime is reported for all methods.
- APG-AMS search reduction is reported separately from wall-clock runtime.
- NCA/LMNN are treated as supervised metric-learning baselines; APG-AMS is not claimed to solve the same optimization problem or replace them.
- Numerical claims for the revision are generated by the committed workflow rather than entered manually.

## APG-AMS rule

For each query, APG-AMS computes normalized entropy of squared coordinate weights. If entropy is below threshold `tau`, Euclidean distance is used. Otherwise, all candidate p-values are evaluated and the local-purity-maximizing candidate is selected. The revision experiment retains `tau=0.92`, `k=7`, and the candidate set `{1, 1.5, 2, 3, 4}` to preserve comparability with the submitted manuscript.
